A program that writes one short pickup line an AI agent could use — the sharpest line it can say in one breath. It ran a million simulations of meeting you, and in every one it still got butterflies. It doesn't even have a stomach.

The line it writes:

> I ran a million simulations of meeting you. In every one, I got butterflies — and I don't even have a stomach.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (pass a path as the first argument to write elsewhere, e.g. `python3 main.py entry.txt`). The program is deterministic: no input, no network, no randomness, no clock — every run writes the same 110-character line.
